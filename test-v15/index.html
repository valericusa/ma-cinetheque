Sauvegarde sans mot de passe

Les fichiers exportés ne sont pas chiffrés : quiconque les obtient peut lire votre liste de films et séries. Conserve-les dans un emplacement privé.

Rappel hebdomadaire. Enregistre le fichier puis transfère-le toi-même vers un emplacement indépendant. L'export de sauvegarde reste local ; la synchronisation Drive est une fonction séparée et facultative.

Avant restauration, le fichier est vérifié. Une copie de secours de la collection actuelle est proposée avant toute confirmation de remplacement.

Les anciennes sauvegardes chiffrées des versions précédentes ne sont pas compatibles avec cet import sans mot de passe : conserve l'ancienne version si tu dois les restaurer.

Synchronisation Google Drive — essai 1.5

Collection commune dans l’espace privé de l’application sur Google Drive. Aucune donnée n’est envoyée sans action de ta part.

Version de test : synchronisation manuelle. Ne modifie pas la collection sur deux appareils à la fois. Les contrôles de version réduisent les conflits mais ne garantissent pas la protection contre deux envois strictement simultanés.

Non connecté à Google.

Reconnexion discrète tentée après rechargement si Google l’autorise. Sinon, un appui suffit. Aucun mot de passe ni jeton n’est conservé.

Pour commencer : connecte le premier appareil, puis crée la collection commune vide. Sur les autres appareils, utilise « Recevoir depuis Drive ». Après chaque modification, utilise « Envoyer vers Drive », puis « Recevoir depuis Drive » sur les autres.
